# Probe Commands

The `probes` group (alias `probe`) lists the latest **cluster-alive probe** per environment — the
"is it still up?" half of day-2, alongside [drift](/cli/commands/drift)'s "has it diverged?". A
`PROBE_CLUSTER` job dials each environment's cluster API server; this shows the most recent result.

<Callout type="info">
The CLI is a client of the same Console API. `probes list` calls `/cli/projects/<project>/probes`
with your [CLI token](/cli/authentication) and operates on the **active organization**, which you
change with `alethia org switch`. Pass `--org <id>` to scope a single invocation to a different
organization — it is refused with `403` if you are not a member of it.
</Callout>

## `alethia probes list`

List a project's latest per-environment cluster probes.

```bash
alethia probes list
alethia probes list --project my-project
alethia probes list -p my-project -o json
```

Name the project with `--project`; omit it at a terminal and you are asked which project to read,
from the ones you have.

{/* fieldspec: alethia probes list */}

| Field | What it is | Set with |
|-------|------------|----------|
| Project | Whose environments to report the latest cluster probe for | `--project` |

Columns: **Environment**, **Reachable** (`● up`, `○ down`, or `— never probed`), **Message** (why
unreachable, when down), **Probed** (when the last probe ran, to the minute in UTC). Every
environment is listed; one that has never been probed shows `never probed` rather than being
hidden.

```
Environment  Reachable        Message             Probed
production   ● up             —                   2026-01-01 00:00
staging      ○ down           dial tcp: timeout   2026-01-01 00:00
dev          — never probed   —                   —
```

Add `-o json` for the raw probe objects — the `probed_at` there is the wire's unrounded RFC 3339
timestamp, not the table's rendering; `-o csv` for the rows. Backing call:
`GET /cli/projects/<project>/probes`.
